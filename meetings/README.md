# Meetings

Weekly session notes for the FSB Design Group 2 squad, pulled directly from Zoom (AI Companion summary + verbatim transcript) via the Zoom MCP connector — no manual copy-paste.

## Structure

- One dated HTML page per session: `YYYY-MM-DD-topic-slug.html`
- Notes (quick recap, next steps, topic summary) are the main content
- The full timestamped transcript is a collapsed "Full transcript" section — click to expand, not the first thing you see

## Adding a new entry

Ask the agent to pull the week's meeting (by topic + date) and generate the page — it can find the meeting via the Zoom connector's `search` tool without needing a shared link. Then add a row to the "Meetings" section on the root [`index.html`](../index.html).
